> 更新日期：2026-04-20

## 一、项目概述

### 1.1 背景与目标

校园内车辆与行人混行问题日益突出，传统人工监控效率低、成本高，难以实现实时预警和数据统计。本系统基于 **YOLOv8** 深度学习目标检测框架，结合多目标跟踪算法，构建了一套适用于校园场景的交通目标检测、计数与安全预警平台。

**核心目标：**
- 实时识别校园内车辆（汽车、摩托车、自行车等）与行人
- 统计目标数量、上下行流量
- 检测碰撞风险、违规区域入侵，并发出预警
- 提供直观可操作的图形界面（GUI），降低使用门槛

### 1.2 系统能力总览

| 能力 | 说明 |
|------|------|
| 多目标检测 | 基于 YOLOv8，支持行人、汽车等多类别 |
| 多目标跟踪 | 自研轻量级跟踪器（IoU + 中心距 + 尺寸相似度） |
| 会话级计数 | 对同一车辆跨轨迹断连的重关联去重计数 |
| 上下行计数 | 基于检测线穿越方向判断 |
| 速度估计 | 像素位移 × 标定系数 → km/h，EMA 平滑 |
| 碰撞预警 | 车辆间距分级预警（高危 / 中危） |
| 违规区域检测 | 多边形 ROI 区域入侵检测（禁停、禁行等） |
| GUI 界面 | PyQt5 多模式界面，支持摄像头 / 视频 / 图片 |
| 推理设备选择 | 自动 / CPU / GPU 三档 |
| 性能监控 | 显示 FPS / 处理 FPS / 模型 FPS 及各阶段耗时 |

## 三、核心模块详解

### 3.1 目标检测（YOLOv8）

- 使用 Ultralytics YOLOv8 进行推理，支持 `n/s/m/l/x` 各尺寸模型。
- 推理设备通过 `resolve_runtime_device()` 动态解析，支持 Auto / CPU / GPU。
- 图像尺寸档位：视频模式下支持 720p / 1080p 工作分辨率切换。
- 置信度阈值（conf）和 IOU 阈值（iou）可在 GUI 实时调节。

**模型加载优先级：**
1. `runs/detect/train/weights/best.pt`（训练后最优模型）
2. `models/yolov8n.pt`
3. `models/yolo26n.pt`
4. 网络自动下载 `yolov8n.pt`

### 3.2 多目标跟踪（tracker.py）

自研轻量级跟踪器，不依赖 DeepSORT 等重量级框架。

**关联策略（三要素打分）：**
- IoU 重叠度
- 中心点欧氏距离
- 边界框尺寸相似度（面积比 + 宽高比加权）

**Track 数据结构：**

```python
@dataclass
class Track:
    track_id: int
    class_id: int
    class_name: str
    bbox: List[float]      # [x1, y1, x2, y2]
    confidence: float
    center: Tuple[float, float]
    age: int               # 未匹配帧数
    hits: int              # 累计匹配次数
    history: List[Tuple]   # 最近 30 帧中心点轨迹
```

### 3.3 计数模块（counter.py）

包含三个独立计数器：

#### ClassCounter（实时类别计数）
- 统计当前帧各类别目标数量。

#### VehicleSessionCounter（会话级唯一计数）
- 通过 track_id 关联，对短时断开的轨迹进行轻量级重关联。
- 重连窗口：45 帧；打分权重：距离（65%）+ 尺寸相似度（35%）。
- 输出：`unique_vehicle_total`（会话总计）/ `current_vehicle_count`（当前帧）。

#### LineCounter（上下行穿越计数）
- 基于向量叉积判断目标穿越检测线的方向。
- 支持任意方向检测线，自动计算法向量。
- 输出：各类别上行 / 下行计数。

### 3.4 速度估计（speed_estimator.py）

```
速度 = 平均每帧像素位移 ÷ pixels_per_meter × fps × 3.6  [km/h]
```

- 窗口大小：最近 5 帧位移取平均。
- 平滑方式：指数移动平均（EMA），平滑因子默认 0.3。
- 依赖像素/米标定参数（`calibration.py` 提供）。

### 3.5 碰撞预警（collision_warner.py）

- 目标范围：仅对车辆类型目标进行检查。
- 距离度量：边界框最小距离（重叠时退化为中心点距离）。
- X 轴粗筛：按 X 坐标排序后提前剪枝，降低复杂度。
- 预警等级：
  - **高危**（red）：距离 < `safe_distance`（默认 5 m）
  - **中危**（orange）：距离 < `warning_distance`（默认 10 m）

### 3.6 违规区域检测（zone_detector.py）

- 支持多边形 ROI 区域（禁停 / 禁行 / 专用车道 / 自定义）。
- 使用 `cv2.pointPolygonTest` 判断目标中心是否在区域内。
- 区域配置可通过 JSON 持久化保存与加载。
- GUI 支持鼠标交互绘制多边形区域。

## 四、GUI 架构

### 4.1 模块职责划分

| 文件 | 职责 |
|------|------|
| `GUI.py` | 程序入口，启动主窗口 |
| `window.py` | 主窗口编排、模式切换、参数绑定、启停控制 |
| `runtime.py` | 视频读取线程、检测线程、预览帧生成、性能统计 |
| `presentation.py` | KPI 面板、分类统计、预警事件展示逻辑 |
| `widgets.py` | `VideoDisplayLabel`（视频帧显示）、`StableVideoViewport`（稳定视口） |

### 4.2 检测流水线（runtime.py）

```
视频解码 (decode)
    → YOLOv8 推理 (model)
    → 目标分析 (analysis)：跟踪 / 计数 / 速度 / 预警 / 违规
    → 帧绘制 (draw)：检测框 / 轨迹 / 标注
    → 预览生成 (preview)：缩放 / BGR→RGB
    → 主线程拉取 (present)：QImage → QPixmap 刷新
```

各阶段耗时在 GUI 底部实时展示。

### 4.3 检测模式

| 模式 | 输入源 | 说明 |
|------|--------|------|
| 摄像头实时检测 | Camera index 0 | 实时推流 |
| 视频文件检测 | mp4 / avi / mov / mkv / flv | 支持暂停 / 继续 |
| 图片文件检测 | jpg / jpeg / png / bmp / webp | 单帧推理，不显示 FPS 叠加 |

### 4.4 GUI 信息区域布局

```
┌─────────────────────────────────────────────────────────┐
│  视频预览区（VideoDisplayLabel）                          │
├───────────────────┬────────────────┬────────────────────┤
│  分类统计          │  当前预警       │  事件流水           │
│  行人: 5          │  [高危] ID3-7  │  12:01 ID3 高危     │
│  汽车: 3          │  [中危] ID2-9  │  12:01 ID5 进入禁区 │
├───────────────────┴────────────────┴────────────────────┤
│  显示FPS: 28.4  处理FPS: 23.7  模型FPS: 118.3           │
│  decode:34ms  model:8ms  draw:2ms  preview:6ms           │
└─────────────────────────────────────────────────────────┘
```

## 五、性能基线

基于当前代码在本地 Windows 环境（CPU 推理）的实测数据：

| 指标 | 数值 |
|------|------|
| 显示 FPS | ~28.4 |
| 处理 FPS | ~23.7 |
| 模型 FPS | ~118.3 |
| decode 耗时 | ~34.4 ms（当前主瓶颈）|
| model 耗时 | ~8.5 ms |
| analysis 耗时 | ~0.7 ms |
| draw 耗时 | ~2.6 ms |
| preview 耗时 | ~6.0 ms |
| present 耗时 | ~2.3 ms |

**瓶颈分析：** 当前主瓶颈在于 OpenCV 视频解码（decode）与帧缩放 / QImage 转换（preview），而非模型推理本身。

## 七、开发规范

### 7.1 文件命名

- 模块文件：小写下划线（`tracker.py`、`zone_detector.py`）
- 类名：大驼峰（`YOLOv8GUI`、`CollisionWarner`）
- 函数/变量：小写下划线（`check_violations`、`pixels_per_meter`）

### 7.2 路径处理

- Windows 路径使用原始字符串：`r"E:\path\to\file"`
- 配置文件路径使用正斜杠或双反斜杠
- 所有文件操作使用完整绝对路径

### 7.3 导入顺序

```python
# 1. 标准库
import os, sys, math
# 2. 第三方库
import cv2, numpy as np
from PyQt5.QtWidgets import ...
```
